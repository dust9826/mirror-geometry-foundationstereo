기존 연구의 공백과 핵심 가설

기존 연구 두 갈래

  • 전용 분할 네트워크 (MirrorNet, PMD)
    → 거울 영역만, 3D 기하(법선·거리) 없음
  • 반사 활용 3D 복원 (MirrorGaussian, Reflect3r)
    → 거울평면이 주어졌다고 가정

→ 검출과 평면 기하를 동시에, 그것도 이미 있는 스테레오 모델 내부에서 얻는 시도는 없었음

핵심 가설

"거울이 유발하는 정합 불안정성 자체가
거울의 prior가 된다"

  • FoundationStereo 가중치는 완전 동결 (재학습 0)
  • 순전파 1회의 내부 prior만 사용

함정: 단순 평면 적합은 "반사면"을 잡는다

  • 거울 안 점군 = 거울 뒤 가상공간의 점들
  • RANSAC 평면 적합 → 거울면이 아니라 반사된 벽/바닥이 잡힘
  • 실측: 진짜 거울면보다 약 2배 깊음

computer_room 예시

단순 적합 6.96 m  vs  GT 거울면 3.24 m

→ 거울 내부 깊이만으로는 원리적으로 불가능
→ 해법: 반사 대칭

거울 내부 점 RANSAC inlier(초록) — 전부 거울 너머 가상공간

해법: 반사 대칭 RANSAC (학습 없음)

성질 1. 가상점 P′와 실제점 P는 평면 M=(n, d)에 완전 대칭

P = P′ − 2(n·P′ + d) n

성질 2. 대응쌍 하나로 평면이 닫힌형 결정 (수직이등분면)

n = (P−P′)/‖P−P′‖,   d = −n·(P+P′)/2

  1. 마스크 침식 내부 P′ / 팽창 외부 방 점 Q 분리
  2. 무작위 쌍 4,000개 → 이등분면 가설
  3. 반사 후 절사(trimmed) 최근접 거리로 점수화
    거울은 관측 밖(카메라 뒤)도 비춤 → 무대응 점 절사 필수
  4. 상위 가설 ICP식 8회 정제 (닫힌형 재추정)
가상점(빨강)을 추정 평면으로 반사(초록) → 방 점군(회색)과 정합.
추정 평면(주황 3.23m) = GT(파랑 3.24m)

평가 인프라: 거울평면 GT를 갖춘 벤치마크 구축

  • Reflect3r .blend 원본 → 스테레오 재렌더 (1280×720)
  • 카메라 교란(±0.3m, ±5°)으로 장면당 55~66뷰
  • 뷰마다: 거울 마스크 + GT depth/disparity + 3D 거울평면 GT
  • 마스크는 재질 기준 객체 인덱스 패스 — 평면 GT와 IoU 0.88~0.98 교차검증

입증한 것

  • 거울 불안정성 정량화: disp 오차 41배, AHCF 후 신호 강화 (0.51→0.75, feat 0.80)
