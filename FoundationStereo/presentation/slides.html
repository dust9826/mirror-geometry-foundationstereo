03 방법 — 해법: 반사 대칭 RANSAC (학습 없음)

성질 1. 가상점 P′와 실제점 P는 평면 M=(n, d)에 완전 대칭

P = P′ − 2(n·P′ + d) n

성질 2. 대응쌍 하나로 평면 결정 — 수직이등분면 (닫힌형)

n = (P−P′)/‖P−P′‖,   d = −n·(P+P′)/2

  1. 마스크 침식 내부 P′ / 팽창 외부 방 점 Q 분리
  2. 무작위 쌍 4,000개 → 이등분면 가설
  3. 반사 후 절사(trimmed) 최근접 거리로 점수화
    거울은 관측 밖(카메라 뒤)도 비춤 → 무대응 점 절사 필수
  4. 상위 가설 ICP식 8회 정제 (닫힌형 재추정)
가상점(빨강)을 추정 평면으로 반사(초록) → 방 점군(회색)과 정합
추정 평면(주황 3.23 m) = GT(파랑 3.24 m)
04 데이터셋 — 거울평면 GT 벤치마크 구축
  • Reflect3r .blend 원본 → 스테레오 재렌더 (1280×720)
  • 카메라 교란(±0.3 m, ±5°) → 장면당 55~66뷰
    거울의 겉보기 크기·각도 다양성 확보

  • 마스크 ↔ 평면 GT 교차검증 (IoU 0.88~0.98)
