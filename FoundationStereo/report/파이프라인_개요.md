# 파이프라인 개요 (코드·데이터 흐름 설명)

> 스테레오 입력 → FoundationStereo prior → 거울 검출/기하 추정의 전체 흐름과 각 스크립트의 역할.
> 코드: `scripts/`, 실험 출력: `experiments/<scene>/`.

## 0. 무엇을, 왜

**목표:** 스테레오 사진 한 쌍만 넣으면, **FoundationStereo(FS)**가 내부적으로 이미 계산해 둔 정보("prior")만으로 사진 속 거울의 기하 정보(위치 / 평면 / 법선 / 크기)를 뽑아내, MirrorGaussian(거울 3D 재구성)에 넘긴다.

**핵심 가설:** 거울은 물리적으로 골치 아픈 물체다. 좌/우 카메라가 거울을 보면 반사된 다른 장면이 보이므로 좌우 매칭(photometric consistency)이 깨진다. 그래서 FS는 거울 영역에서 "불확실하게 매칭"하거나 "거울 너머 반사된 깊이"를 본다. → **이 비정상성 자체가 거울을 찾는 신호**가 된다. FS를 재학습하지 않고, FS가 흘리는 신호를 읽기만 하면 된다.

## 1. 입력 데이터 (어디서 오나)

```
../MakeStereoDataset/data/stereo_dataset/<scene>/
   ├── left.png            # 좌 카메라
   ├── right.png           # 우 카메라  (baseline 0.08m)
   └── mirror_mask_left    # 거울 영역 정답 마스크 (Blender 렌더 시 추출, 평가/학습용)
```

- 자매 프로젝트 **MakeStereoDataset**가 Blender 17개 실내 장면에서 렌더링한 합성 스테레오 데이터.
- 거울은 "흰 사각형"이 아니라 **물리 반사를 실제로 렌더** → FS가 거울을 통과해 반사된 장면의 깊이를 본다(이게 나중 한계의 원인).
- 카메라 내부행렬 K는 가정값(렌즈 50mm/센서 36mm). **disparity엔 무관, depth/거리 스케일만 영향.**
  - ※ 후속 발견: 실제 lens는 장면별 25–60mm로 가정값과 다름 → 절대 거리 척도 보정 필요(자세한 내용은 연구기록 참고).

## 2. 파이프라인 단계

```
prepare_data → run_foundation_stereo → estimate_mirror_plane → analyze_features → (submodel_head)
```
(`run_pipeline.py`가 순서대로 호출. `run_pipeline_full.py`는 여기에 viz_ransac_inliers·GT·submodel_applied까지 포함.)

### ① `prepare_data.py` — 입력 정리
원본 장면에서 left/right/mirror_mask를 `experiments/<scene>/input/`으로 복사하고, `K.txt`(intrinsic)와 `prepare_meta.json`(해상도·baseline·카메라 extrinsic 4×4)을 만든다.

### ② `run_foundation_stereo.py` — FS 추론 + prior 추출 (이 프로젝트의 심장)
FS를 한 번 forward 시키며 `forward_hook`으로 내부 중간 텐서를 가로챈다:

| 추출물 | 정체 | 의미 |
|---|---|---|
| `disp` / `depth_meter` / `points` | 최종 disparity → depth → 3D 점 | 거울 영역은 "반사된 장면 깊이"가 찍힘 |
| `feat_left` (128채널) | side-tuning 2D 특징 | FS가 보는 이미지 의미 특징 |
| `corr_stem` 출력 = `cost_pre` | **AHCF 이전** cost volume | 원시 매칭 비용 |
| `cost_agg` 출력 = `cost_post` | **AHCF 이후** cost volume | 집계된 매칭 비용 |

두 cost volume에 **똑같은 `model.classifier`**를 적용해 disparity 분포를 만들고, 픽셀별로 `conf`(분포 최댓값), `entropy`(불확실성), `argdisp`(argmax)를 `pre_*`/`post_*`로 저장 → **AHCF 전/후를 같은 잣대로 비교**.

> 코드 디테일: depth 저장 시 z_far 클리핑을 **안 함**. 거울 반사 깊이가 멀어 잘리면 분석 대상이 사라지기 때문. ply 시각화에만 클리핑.

### ③ `estimate_mirror_plane.py` — 거울 "평면" 피팅 (`mirror_geometry.py` 사용)
거울 마스크 영역 3D 점에 평면 피팅, 3방법 비교: `pca`(최소제곱) / `ransac`(강건) / `svd_robust`(IRLS). → `result.json`에 normal, d, inlier, residual, mirror_depth, plane_bbox, image_bbox, `reflection_matrix_4x4`(Householder) 저장.
- 발견: RANSAC rms ≈ 0.027m vs PCA rms ≈ 0.43m → RANSAC 압도적 강건. **단 적합 평면은 거울면이 아니라 "반사면"**(한계).

### ④ `analyze_features.py` — RQ 검증 (AHCF가 신호를 만드는가?)
거울 마스크를 라벨로, `pre_*` vs `post_*` 신호가 거울을 얼마나 분리하는지 AUC로 측정.
- 발견: AHCF **이전** AUC ≈ 0.51(우연) → **이후** 0.65~0.68로 상승. **"AHCF 단계가 거울 신호를 만든다"** 입증.

### ⑤ `submodel_head.py` — 경량 학습 헤드 (접근 #3)
FS 동결, 픽셀당 **136차원**(feat_left 128 + cost 통계 8: pre/post의 conf·entropy·argdisp + delta_conf + delta_entropy) 위 작은 MLP(은닉 64)만 학습.
- 단일 scene(70/30): AUC ~0.99 / IoU 0.85~0.92
- LOSO(미지 scene, 12-fold): 평균 AUC 0.91 / IoU 0.45 → **FS prior가 거울-ness를 인코딩**(작은 거울 bedroom은 약함)
- `apply_submodel.py`로 train(범용 head 저장)/apply(새 scene) 분리.

> ⚠️ 함정: 서브모델 입력 특징은 **같은 체크포인트**로 뽑아야 함. ViT-S=136차원 vs ViT-L=232차원.

## 3. 추가 스크립트 (확장)

| 스크립트 | 역할 |
|---|---|
| `run_pipeline_full.py` | 단일 scene 전체(FS→평면→ransac_inliers→AHCF→submodel→submodel_applied→GT-from-depth) |
| `viz_ransac_inliers.py` | RANSAC inlier/outlier 3패널 시각화 |
| `make_mirror_gt.py` / `export_mirror_gt.py` | Blender 원본에서 GT 거울평면 추출 |
| `make_mirror_gt_from_depth.py` | GT depth가 있으면 역투영으로 GT 거울평면(Blender 불필요) |
| `eval_mirror_plane.py` | 추정 vs GT 평면: 법선각 + 모서리거리 |
| `eval_gt_depth.py` | FS depth/disparity 정확도(거울 vs 비거울) |
| `prepare_views_archive.py` / `run_archive_batch.py` | 신규 데이터셋(ds_v1) 준비·일괄 실행 |
| `rerender_mask.py` / `probe_mirrors.py` | 거울 마스크 재렌더·거울 객체 진단 |
