# Mirror Geometry / FoundationStereo — RQ1·RQ2 연구 기록

> 스테레오 입력과 FoundationStereo prior 만으로 거울을 검출·기하 추정하는 파이프라인의
> 전체 실험·시행착오 기록. 데이터: `experiments/legacy/` (17개 합성 장면), 코드: `scripts/`.

---

## 1. 프로젝트 개요

### 1.1 연구 목표
스테레오 이미지에서 거울의 기하 정보(Mirror Geometry)를 추출해 **MirrorGaussian** 입력으로 제공한다. 별도의 end-to-end 거울 분할 네트워크를 학습하는 대신, **FoundationStereo**(FS)가 이미 보유한 prior(side-tuning 특징, cost-volume 통계)만으로 거울의 영역(mask/bbox), 깊이($d$), 평면 법선($n$)을 추정한다. 핵심 가설: **거울이 유발하는 스테레오 정합 불안정성 자체가 거울을 가리키는 prior가 된다.**

### 1.2 연구 질문
- **RQ1**: FS의 **AHCF**(Attentive Hybrid Cost Filtering) 단계 전/후 특징을 비교해 거울을 특정하는 신호가 생기는지 확인하고, 그 신호로 거울을 **검출**한다.
- **RQ2**: FS 출력(disparity/point cloud/feature)으로 거울 **평면** $n\cdot x + d = 0$ 을 추정하고 정답(GT)과 비교한다.

### 1.3 실험 환경
- 로컬 GPU RTX 5070 Ti = **Blackwell(sm_120)**. repo의 torch 2.4.1(cu121) 미지원 → **torch 2.7.1+cu128** 사용. flash-attn 불필요(코드에서 SDPA 사용), xformers 선택.
- 데이터셋: MakeStereoDataset(Blender 물리 반사 렌더, 1024×576, baseline 0.08m)로 만든 17개 실내 장면 + 장면별 거울 마스크 GT. 일부 장면은 다른 시점(minigym_view04).

## 2. 파이프라인 구성 (생산자/소비자)

FS를 한 번만 추론해 prior를 디스크에 저장(생산자)하고, 분석은 저장된 prior만 읽어(소비자) 재추론 없이 반복한다.

```
left/right.png ──(FS 1회 추론)── run_foundation_stereo.py
   │  forward hook 으로 prior 추출:
   │   - feat_left (side-tuning 128채널)
   │   - corr_stem 출력 = AHCF '이전' cost volume → classifier → conf/entropy/argdisp (pre_*)
   │   - cost_agg 출력 = AHCF '이후' cost volume → 같은 classifier → (post_*)
   │  저장: fs/{disp,depth_meter,points,conf,entropy}.npy, fs/features.npz
   ▼
소비자(FS 재추론 X):
   estimate_mirror_plane.py  → 평면 RANSAC/PCA/IRLS (mirror_geometry/result.json)
   analyze_features.py       → AHCF 신호별 거울 분리 AUC (features/report.json, panels.png)
   submodel_head.py / apply_submodel.py → 경량 검출 헤드 (submodel/, submodel_applied/)
   make_mirror_gt.py         → Blender 원본에서 GT 거울평면 (mirror_gt/gt.json)
   eval_mirror_plane.py      → 추정 vs GT 평면 (법선각/모서리거리)
```

장면당 출력: `input / fs / mirror_geometry / features / submodel / (submodel_applied) / mirror_gt`.

### AHCF hook 지점
`core/foundation_stereo.py` forward에서 `comb_volume = self.cost_agg(...)`가 AHCF 전체(APC + Disparity Transformer)다. 따라서:
- `corr_stem` 출력 = AHCF 입력(pre), `cost_agg` 출력 = AHCF 출력(post)을 forward hook으로 캡처.
- 두 cost volume에 **동일한 `model.classifier`** 를 적용해 disparity 분포의 conf/entropy/argmax를 같은 잣대로 비교.

## 3. RQ1 — AHCF 거울 신호와 검출

### 3.1 RQ1-a: AHCF가 거울 신호를 "만든다"
각 신호(conf, entropy, argdisp 및 delta = post−pre)가 거울 마스크를 분리하는 **ROC AUC**로 정량화.

**결과**: AHCF **이전** 신호는 우연 수준(AUC ≈ 0.51), **이후/delta** 신호는 상승. 거울 신호는 입력 특징이 아니라 **AHCF 집계 단계에서 생성**된다.

| 장면 | PCA rms(m) | RANSAC rms(m) | 최고 AHCF 신호 (AUC) | 검출(submodel) AUC/IoU |
|---|---|---|---|---|
| archiviz | 0.427 | 0.047 | delta_conf (0.55) | 0.992 / 0.85 |
| blue_bathroom | 0.291 | 0.034 | delta_argdisp (0.67) | 0.995 / 0.87 |
| computer_room | 0.430 | 0.027 | delta_entropy (0.68) | 0.988 / 0.85 |
| cozy_living_room | 0.804 | 0.040 | post_conf (0.59) | 0.999 / 0.92 |
| green_house | 0.464 | 0.026 | post_entropy (0.74) | 0.985 / 0.73 |
| gym | 0.919 | 0.062 | delta_argdisp (0.60) | 0.989 / 0.85 |
| modern_living_room | 0.124 | 0.040 | feat_left_pc1 (0.80) | — |
| scandinavian | 0.644 | 0.051 | post_entropy (0.75) | 0.996 / 0.88 |
| sunlight | 0.707 | 0.047 | feat_left_l2 (0.57) | 0.989 / 0.83 |

> 신호 세기는 **장면 의존적**이다. 반사가 방과 연속적(텍스처 풍부한 장면을 비추는 거울)인 경우 AHCF 신호가 약하고(gym 0.60), 반사가 덜 연속적인 장면은 강하다(modern_living_room 0.80, scandinavian 0.75, green_house 0.74).

### 3.2 RQ1-b: FS prior 위 경량 검출 헤드
FS 동결, **픽셀당 136차원**(feat_left 128 + cost 통계 8) 위에 작은 MLP(은닉 64)만 학습.

- 단일 장면(70/30 분할): AUC ~0.99 (cozy 0.999 / IoU 0.92).
- **미지 장면 일반화 (LOSO, 12-fold)**: 평균 AUC **0.911**, 중앙값 0.939, 평균 IoU 0.454.

| LOSO 장면 | AUC | IoU |  | LOSO 장면 | AUC | IoU |
|---|---|---|---|---|---|---|
| archiviz | 0.968 | 0.684 |  | gym | 0.947 | 0.598 |
| bedroom | 0.731 | 0.053 |  | livingroom | 0.864 | 0.424 |
| blue_bathroom | 0.965 | 0.420 |  | minimal_interior | 0.893 | 0.344 |
| computer_room | 0.956 | 0.689 |  | scandinavian | 0.873 | 0.437 |
| cozy_living_room | 0.931 | 0.245 |  | sunlight | 0.884 | 0.450 |
| green_house | 0.956 | 0.426 |  | flat-archiviz | 0.968 | 0.684 |

- 교차-시점: 12개 장면 학습 → 전혀 다른 시점 **minigym_view04** 적용 AUC **0.947 / IoU 0.737**.
- 약점: 작은 거울(bedroom IoU 0.053).

### 3.3 RQ1 결론
FS prior(특히 AHCF 이후 신호 + side-tuning 특징)는 **거울다움을 장면 무관하게 인코딩**한다. 경량 헤드만으로 미지 장면 AUC 0.911, 교차-시점 0.947. 즉 **검출(어디 있는가)은 prior로 해결**된다. AHCF 신호 단독 분리력은 장면에 따라 다르지만, 신호들을 결합한 검출 헤드는 강건하다.

## 4. RQ2 — 거울 평면

### 4.1 RANSAC은 강건하나 "반사면"을 잡는다 (Virtual Depth)
완전 반사면은 자기 텍스처가 없어 stereo는 거울에 비친 **가상 장면**을 매칭한다. 따라서 거울 마스크 내부 3D 점에 평면을 피팅하면:
- RANSAC이 PCA보다 한 자릿수 낮은 잔차(예 computer_room PCA 0.430 → RANSAC 0.027m) — **강건성은 확인**.
- 그러나 그 평면은 거울면이 아니라 **반사면**. computer_room RANSAC 수직거리 ≈ 9.5m(가정 K 기준)로 거울 테두리 벽보다 훨씬 깊다.

거울면 $M$은 실제 점 $P$와 반사점 $P'$의 **수직이등분면**이므로, 반사점 $P'$만으로는 복원이 불가능하다. 이것이 RQ2의 근본 난점이다.

### 4.2 GT 거울평면 인프라 (Blender)
정답 거울평면을 Blender 원본에서 추출. `export_mirror_gt.py`(Blender)가 거울 메쉬 정점을 world 최소제곱 평면으로 피팅 → `make_mirror_gt.py`가 좌측 카메라 OpenCV 좌표로 변환:

```
M = F · C⁻¹,   F = diag(1, −1, −1)  (Blender −Z전방/+Y상 → OpenCV +Z전방/+Y하)
n_cam = R · n_world,   d = −n·c
```

- **16 scene / 37 거울** GT 생성. Blender↔데이터셋 카메라 일치(ext_diff ≈ 0). 재투영 overlay가 거울 마스크와 겹쳐 변환 검증.
- 거울 객체는 **데이터셋이 실제 렌더에 쓴 `prepare_meta.mirror_objects`** 우선 사용(GT·마스크 거울 일치). 잘못 잡힌 장면만 교정(§6).

### 4.3 ★중대 발견: 데이터셋 초점거리(K) 가정 오류
GT overlay가 마스크와 안 맞아 디버깅한 결과, 데이터셋이 `lens = 50mm`로 **가정**했으나 Blender 실제 값이 장면마다 다름:

| 실제 lens | 장면 |
|---|---|
| 25–26mm | green_house(25), minigym(25.7), cozy/livingroom(26) |
| 28–30mm | modern_living_room(28), computer_room/gym/loft/scandinavian(30) |
| 35mm | sunlight |
| 50mm | archiviz, flat-archiviz, terrazzo, bedroom, blue_bathroom |
| 60mm | minimal_interior |

- 영향: `points.npy` depth = fx·baseline/disp 이므로 절대 깊이가 (50/실제)배 어긋남(computer_room ×1.667). 보정 시 RANSAC 반사면 참 거리 ≈ 5.7m로 GT 거울면 3.24m의 약 1.76배.
- 단 **disparity 기반 결론(검출·AHCF AUC)과 GT 기하(절대 미터)는 K 무관**. 영향은 절대 거리 척도에만 국한.
- GT 도구가 장면별 실제 K를 추출·저장(overlay·평가에 사용).

### 4.4 평가 지표: 법선각 + 모서리거리
거울을 평면(법선 $n$, 4모서리)으로 표현하고 추정 vs GT를 비교(`eval_mirror_plane.py`):
- **Normal Angle** = $\arccos(|n_{est}\cdot n_{gt}|)$ (180° 뒤집힘 무관)
- **Corner distance** = 두 사각형 4모서리 대칭 최근접(chamfer) 평균 거리(순서 무관)
- (보너스) perp 오차, center 거리

현재 추정 = RANSAC 반사면(정공법 미구현)으로 16장면 평가 → 중앙값 **Normal Angle 77.8°, Corner distance 4.9m, perp 오차 3.4m**. 반사면이 거울면과 거의 수직(최대 89°)으로 어긋남 — Virtual Depth 함정을 16장면 규모로 정량화. (bedroom만 2.66°로 반사면이 우연히 거울면과 평행.)

> 이 평가 인프라는 정공법이 거울평면을 추정해 `result.json` 형식으로 주면 그대로 점수가 나오도록 준비됨. RANSAC 반사면이 baseline.

## 5. RQ2 정공법(미구현) — 설계

거울의 **반사 대칭**을 직접 이용한다. `reflect_M({거울 안 P'})`가 방 점 {P}와 겹치도록 거울면 M을 최적화(RANSAC+ICP 또는 3대응 closed-form). 순수 기하, 학습 불필요. 어려운 점 = 대응 찾기/퇴화. `mirror_geometry.py`에 평면피팅·`reflection_matrix`(Householder 4×4)·`plane_bbox` 라이브러리가 준비돼 있고, 평가는 §4.4 지표를 사용한다.

| **bedroom** | `find_mirrors`가 이름("Mirror1~4") 우선이라 작은 엉뚱한 객체 선택(마스크 3.6%). 실제 거울 = 옷장 미러도어 | `Wardrobe_04_001.*`로 교정 → **31.7%**, GT 재생성 |

## 7. 시행착오·디버깅 기록

1. **GT overlay가 마스크와 불일치(초기)** — matplotlib autoscale로 폴리곤이 화면 밖으로 부풀어 판단 불가 + 가정 K(50mm)로 투영이 1.667배 과대. → 축을 이미지 범위 고정 + **실제 K** 사용으로 해결(§4.3 발견의 단서).
2. **좌표 축 플립 검증** — world→cam 변환의 `F=diag(1,−1,−1)`(Blender −Z전방/+Y상 → OpenCV +Z전방/+Y하)를 합성 평면 단위테스트(z전방/y플립/x보존)로 TDD.
3. **find_mirrors의 이름 우선 한계** — `_is_mirror_name`이 "Mirror Wall"을 프레임으로 제외 → minigym에서 실제 거울을 놓침. glossy-union은 과대포함(머그/창/주방 금속). 해결: **`prepare_meta.mirror_objects`(데이터셋 실제 거울) 우선** + 장면 오버라이드.
4. **Windows cp949 인코딩** — `load_meta`가 UTF-8(한글 note) prepare_meta를 cp949로 읽어 `UnicodeDecodeError`. → `open(..., encoding="utf-8")`로 수정.
5. **큐브형 거울(minigym)** — 거울 객체가 평면이 아니라 큐브(`Cube.001~003`)라 평면 GT planarity_rms 1.0m로 신뢰 불가. 미해결 한계.

## 9. 핵심 인사이트 요약

1. **검출과 평면추정은 난이도가 다르다.** FS prior로 거울 **검출**은 미지 장면·시점에서도 안정적(LOSO AUC 0.911, 교차-시점 0.947). 거울 **평면**은 Virtual Depth 함정으로 점군 적합만으론 불가.

2. **AHCF가 거울 신호를 생성한다(정량).** 같은 classifier로 pre/post 비교 시 AUC 0.51 → 최대 0.80. 분리력은 장면 의존적(반사가 방과 연속적일수록 약함).

3. **반사면 ≠ 거울면(16장면 정량).** RANSAC 반사면은 GT 거울면과 법선각 중앙값 77.8°·모서리거리 4.9m로 어긋남. 평면 평가 인프라(법선각/모서리거리)는 정공법 점수용으로 준비됨.

4. **K 가정 오류 발견.** 데이터셋 50mm 가정 ≠ 실제 25–60mm. 절대 깊이 스케일에 영향(disparity·검출·GT 기하는 무관). GT 도구가 실제 K 추출.

5. **거울 식별이 모든 것의 선결.** 이름 우선 find_mirrors가 실제 거울을 놓치는 장면 다수(bedroom 옷장, minigym Mirror Wall, living_room texture-mirror). `prepare_meta.mirror_objects` 우선 + 오버라이드로 해결.

6. **GT 인프라 완비.** Blender 기반 GT 거울평면(16장면)으로 검출(precision/recall/IoU)·평면(법선각/모서리거리) 정량 평가가 모두 가능해짐.
